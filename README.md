# ฟังใจ: เว็บรับฟังปัญหาและข้อเสนอแนะของน้องๆ

เว็บที่น้องๆ เข้าใช้ได้โดย **ไม่ต้องล็อกอิน ไม่ต้องมีอีเมล** แต่ละเครื่องได้รหัสสุ่มของตัวเอง

- ปรึกษาปัญหากับผู้ช่วย AI "พี่" (เรื่องหนักจะขึ้นสายด่วนและแนะนำพบแพทย์)
- เสนอคำแนะนำถึงสภา
- คุยกับเจ้าหน้าที่สภา (เจ้าของตอบได้จากหน้า `/admin`)
- เจ้าของล็อกอินด้วยรหัสผ่านที่ `/admin` เพื่อดูแชท ตอบน้อง จัดการเรื่อง และแก้ข้อความ/คำสั่ง AI/สายด่วนของเว็บได้เอง

ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ใช้เฉพาะ Node.js 20 ขึ้นไป) ข้อมูลเก็บในไฟล์เดียว `data/db.json`

---

## 1) ลองรันในเครื่องตัวเองก่อน

1. ติดตั้ง Node.js เวอร์ชัน 20 ขึ้นไป (nodejs.org)
2. คัดลอก `.env.example` เป็น `.env` แล้วแก้
   - `ADMIN_PASSWORD` รหัสผ่านเจ้าของ อย่างน้อย 8 ตัวอักษร ตั้งให้เดายาก
   - `ANTHROPIC_API_KEY` คีย์จาก console.anthropic.com
3. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน `node server.js`
4. เปิด http://localhost:3000 (หน้าน้องๆ) และ http://localhost:3000/admin (หน้าเจ้าของ)

ถ้ายังไม่ใส่ `ANTHROPIC_API_KEY` เว็บยังทำงาน แต่ผู้ช่วย AI จะบอกน้องว่ายังไม่พร้อม และจะยังขึ้นสายด่วนเมื่อเจอคำเสี่ยง

ทดสอบระบบอัตโนมัติ: `node test/e2e.js` (ใช้ AI จำลอง ไม่เสียค่าใช้จ่าย)

---

## 2) เอาขึ้นเว็บจริง

สิ่งที่ที่โฮสต์ต้องมี
- รัน Node.js ได้ตลอดเวลา
- **ดิสก์ถาวร** สำหรับโฟลเดอร์ข้อมูล (ตั้ง `DATA_DIR`) เพราะข้อความของน้องอยู่ที่นี่ บริการที่ไฟล์หายเมื่อรีสตาร์ต (เช่น แพ็กเกจฟรีบางเจ้า) ใช้เก็บข้อมูลจริงไม่ได้
- HTTPS (จำเป็น เพราะรหัสผ่านเจ้าของและข้อความของน้องส่งผ่านเว็บ)

### ทางเลือก ก: VPS หรือเครื่องเสมือน (Ubuntu) + Caddy

1. ซื้อ/ขอเครื่อง แล้วชี้โดเมนมาที่ IP ของเครื่อง
2. ติดตั้ง Node.js 20+ และ Caddy ตามคู่มือบนเว็บของเขา
3. อัปโหลดโฟลเดอร์นี้ไปที่ `/opt/fangjai` แล้วสร้างไฟล์ `/opt/fangjai/.env` (ใส่ ADMIN_PASSWORD, ANTHROPIC_API_KEY, `TRUST_PROXY=1`, `DATA_DIR=/var/lib/fangjai`)
4. สร้างโฟลเดอร์ข้อมูล: `sudo mkdir -p /var/lib/fangjai`
5. สร้างไฟล์ `/etc/systemd/system/fangjai.service`

```
[Unit]
Description=Fangjai
After=network.target

[Service]
WorkingDirectory=/opt/fangjai
ExecStart=/usr/bin/node server.js
Restart=always
User=www-data
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```
   แล้วรัน `sudo chown -R www-data /var/lib/fangjai && sudo systemctl enable --now fangjai`
6. ตั้ง Caddy (`/etc/caddy/Caddyfile`) ให้ได้ HTTPS อัตโนมัติ

```
ชื่อโดเมนของคุณ.example {
    reverse_proxy 127.0.0.1:3000
}
```
   แล้ว `sudo systemctl reload caddy`

### ทางเลือก ข: Docker

```
docker build -t fangjai .
docker run -d --name fangjai -p 3000:3000 -v fangjai-data:/data --env-file .env fangjai
```
แล้วหน้าด้วยตัวทำ HTTPS ของที่โฮสต์ หรือ Caddy ด้านบน

### ทางเลือก ค: บริการโฮสต์แบบจัดการให้ (Render, Railway ฯลฯ)

ใช้ได้ถ้าเลือกแพ็กเกจที่ **มีดิสก์ถาวร** แล้วตั้ง `DATA_DIR` ให้ชี้ไปที่ตำแหน่งที่เขาติดตั้งดิสก์ให้ ตั้ง Start command เป็น `node server.js` และใส่ค่า environment ตาม `.env.example` ราคาและเงื่อนไขเปลี่ยนบ่อย ตรวจที่หน้าราคาของเจ้านั้นก่อน

## 3) ใช้งานประจำ

- เปิด `/admin` ทุกวันอย่างน้อยวันละครั้ง ดูตัวเลขสีแดง "ต้องดูแลด่วน" และ "รอเจ้าหน้าที่ตอบ"
- รายการที่ AI หรือคำสำคัญประเมินว่าเสี่ยงสูงขึ้นป้าย "ด่วน" และเรียงไว้บนสุด ตั้งสถานะ "ดูแลแล้ว" เมื่อจัดการเสร็จ
- ตอบน้องได้ในรายละเอียดของแต่ละคน น้องจะเห็นเมื่อกลับมาเปิดเว็บ (ไม่มีแจ้งเตือนเด้งไปหาน้อง)
- แท็บ "ตั้งค่าเว็บไซต์" แก้ข้อความ หมวดเรื่อง สายด่วน คำสั่งบุคลิก AI และเปิด/ปิด AI ได้ทันที
- **สำรองข้อมูล:** คัดลอกไฟล์ `db.json` ในโฟลเดอร์ข้อมูลไปเก็บที่อื่นเป็นประจำ (เช่น ทุกวันด้วย cron)

## 4) ความปลอดภัยและความเป็นส่วนตัว

- เก็บ `.env` เป็นความลับ ห้ามอัปโหลดขึ้นที่สาธารณะ
- รหัสน้องเป็นโทเคนสุ่มเก็บในเบราว์เซอร์ ฝั่งเซิร์ฟเวอร์เก็บเฉพาะค่าแฮช ไม่มีชื่อจริงหรืออีเมล
- เครื่องใช้ร่วมกัน: หน้าแรกมีปุ่ม "ล้างข้อมูลในเครื่องนี้" ให้น้องกด
- จำกัดความถี่การใช้งาน และมี `MAX_AI_PER_DAY` เพื่อไม่ให้ค่า AI บานปลาย
- ไฟล์ข้อมูลเก็บข้อความเป็นข้อความธรรมดา ควรจำกัดคนเข้าถึงเครื่องและไฟล์นี้
- เว็บนี้เก็บข้อความของนักเรียนที่อาจอายุไม่ถึง 18 ปี ควรแจ้งโรงเรียนและขอคำปรึกษาเรื่องกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) ก่อนเปิดใช้
- เว็บนี้ไม่ใช่ช่องทางฉุกเฉิน ไม่มีระบบแจ้งเตือนทันที ควรกำหนดคนรับผิดชอบเปิดดูเรื่อง "ด่วน" และช่องทางส่งต่อครูแนะแนวหรือผู้เชี่ยวชาญ

## ไฟล์ในโฟลเดอร์

- `server.js` เซิร์ฟเวอร์และระบบหลังบ้าน
- `defaults.js` ข้อความและคำสั่ง AI เริ่มต้น (แก้ในหน้า /admin ได้ ไม่ต้องแก้ไฟล์)
- `public/` หน้าเว็บของน้องๆ (`index.html`, `app.js`) และหน้าเจ้าของ (`admin.html`, `admin.js`), `style.css`
- `test/e2e.js` ตัวทดสอบอัตโนมัติ
